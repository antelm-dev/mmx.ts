# Attribution and licensing

This starter project bundles gameplay assets derived from fan re-creations and
third-party sources used by the MMX reference implementation.

## Fan work

Sprite sheets, animation metadata, and level conventions follow the Mega Man X
fan re-creation workflow documented in the upstream Godot reference project.
Capcom owns the Mega Man and Mega Man X franchises. This template is provided
for non-commercial fan-game authoring inside MMX Studio and must not imply
official endorsement.

## Sounds

Sound effects were imported from the reference Godot project and its cited source
materials. Preserve this file when copying or exporting the starter project so
downstream builds retain attribution context.

## Fonts

`assets/fonts/mega-man-x.ttf` is a third-party fan font used for HUD typography.
Verify license terms before redistributing modified exports.

## Maintainer note

When refreshing assets from the Godot reference project, update this file if new
third-party sources are introduced.
