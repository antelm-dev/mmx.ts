Show the last run's trail on the level: after Stop, Studio re-simulates the run from its recorded input (same level, game data and clips, a "Play from here" copy included) and draws the player's path as a dashed line, broken at a death, with a dot where the run ended. H shows or hides it; the next run replaces it, and it is never saved with the level. The trace runs in small slices, so Stop never freezes the editor.
