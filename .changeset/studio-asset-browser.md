Add an Assets view to Studio: search the project's tilesets, sprites, animations, images, sounds, enemies (built-in ones flagged) and objects, and open each with a double-click or Enter in its own document tab. The Enemy editor, Clip Editor and Sheet Slicer are now per-asset document tabs that only ever edit their own asset. The Assets view's "Import sprite sheet…" and "New animation…" replace File → Slice Sheet and File → Clip Editor.
