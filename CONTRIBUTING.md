# Contributing to MMX Studio

MMX Studio is a fan project. Read the notice and the rules in the README's
[Fan project](README.md#fan-project) section first: Mega Man characters and
universe © Capcom; this free fan project is not affiliated with or endorsed by
Capcom and distributes no Capcom asset.

## PR checklist

Copy this into the PR description and tick every line:

```markdown
- [ ] No Capcom asset: no sprite, sound, music, ROM, game file or extract of one, in code, tests, fixtures or docs.
- [ ] Test fixtures are synthetic and generated by the test (no file read from a game install is committed).
- [ ] Credits: any third-party content used is credited (origin, author, licence); content packs keep their mandatory credits.
- [ ] Content packs stay user-distributed: nothing in the app downloads, hosts or lists packs.
- [ ] No third-party site URL in the app (no link, fetch or embed to an outside site).
- [ ] `pnpm typecheck`, `pnpm test` and `pnpm build` pass; `pnpm e2e` passes for UI changes.
- [ ] `pnpm-lock.yaml` is not committed unless the change is about dependencies.
```

## Branches

Name branches `<type>/<slug>-<id>`, where `<type>` is the Conventional Commits
type, `<slug>` a short kebab-case topic and `<id>` the task or issue number, for
example `feat/maker-packs-02` or `fix/problems-loop-40`.

## Commits

Use [Conventional Commits](https://www.conventionalcommits.org/):
`<type>(<scope>): <summary>`, with `feat`, `fix`, `docs`, `test`, `refactor`,
`chore`… and a scope such as `ui`, `import`, `theme`. Keep one logical change per
commit, imperative summary, no trailing period. PRs are squash-merged with the
same format and the PR number, e.g. `feat(theme): Light / Dark / System colour mode (#63)`.

Commits authored by an AI agent end with its trailer as the last line, for
example:

```text
Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>
```
